# 3. Core Research Question

本项目不试图预测：“明天一定涨还是跌”。 核心问题是：当前ES市场的波动状态是什么？ 特别研究：
1. Overnight是否处于历史低波动状态？
2. Overnight是否形成Volatility Compression？
3. Compression是否在Pre-market提前释放？
4. 09:30之后是否出现新的Price Discovery？
5. Cash Session是否出现Volatility Expansion？
6. Overnight状态与Cash Session波动之间是否存在稳定的统计关系？

# 4. Fundamental Principle

必须区分：Prediction 与：Regime Detection 本系统首先是：REGIME DETECTION SYSTEM 不是：DIRECTION PREDICTION SYSTEM 因此：LOW RV 不等于：BULLISH LOW RV 也不等于：HIGH PROBABILITY LONG Compression 也不等于：必然Expansion 所有交易相关结论必须通过历史统计验证。

# 12. 5-Minute Bar Standard

# 13. Realized Volatility

基础return：r_t = ln(C_t / C_(t-1)) Realized Variance：RV² = Σ r_t² Realized Volatility：RV = sqrt(Σ r_t²) 同时保存：realized_variance realized_volatility annualized_rv

# 14. RV Definition

V1的核心RV：Close-to-Close Realized Volatility 不允许用：High-Low Range 替代：Realized Volatility Range是独立指标。

# 15. Most Important Statistical Principle

## SAME-ELAPSED-TIME COMPARISON

这是系统最高优先级的统计原则之一。 当前时刻的RV：只能与历史交易日相同Phase、相同Elapsed Time的RV进行比较。

## Example

当前：23:00 ET Today's RV：20:15 → 23:00 Elapsed：165 minutes 必须比较：过去60个交易日：20:15 → 23:00 --- 禁止：今天20:15 → 23:00 vs 历史20:15 → 04:00

# 16. Pre-market Benchmark

例如当前：06:00 Pre-market RV：04:00 → 06:00 历史比较：过去60个交易日：04:00 → 06:00

# 17. Cash Benchmark

例如当前：10:30 Cash RV：09:30 → 10:30 历史比较：过去60个交易日：09:30 → 10:30

# 18. Elapsed-Time Key

Historical Benchmark必须使用：Phase + Elapsed Minutes 作为核心索引。 例如：OVERNIGHT + 165 PREMARKET + 120 CASH + 60 禁止跨Phase比较。

# 19. RV Percentile

当前RV：↓ 寻找历史相同：Phase + Elapsed Time 样本 ↓ 排序 ↓ 计算Percentile

## Interpretation

例如：RV Percentile = 10% 意味着：当前RV处于历史同时间进度的非常低水平。 它不意味着：未来一定发生Expansion。

# 20. Minimum Sample

默认：minimum_history_samples = 20 如果不足：Percentile = UNAVAILABLE 禁止：猜测 填0 插值冒充历史样本

# 21. Overnight Range

从：20:15 开始记录：Running High Running Low Range：High - Low 04:00以后：Overnight High Overnight Low 固定。

# 22. Range Percentile

Range Percentile必须遵循：SAME-ELAPSED-TIME 例如：23:00：Today's Range：20:15 → 23:00 vs 历史：20:15 → 23:00

# 23. Overnight Compression

V1默认：RV Percentile <= 20% 定义：WEAK_COMPRESSION 如果同时：RV Percentile <= 20% AND Range Percentile <= 30% 定义：STRONG_COMPRESSION 否则：NORMAL

# 24. Compression Confirmation

不能因为单个5m Bar满足条件就确认Compression。 默认：2 consecutive bars 配置：compression_confirmation_bars = 2

# 25. Compression Is Not A Signal

Compression只是：Market State 不是：Trade Signal 必须避免：Compression → Buy Call 这种硬编码逻辑。

# 26. Pre-market Transition

04:00以后：Overnight High / Low固定。 监测：Breakout Breakdown RV Expansion RV Acceleration

# 27. Breakout

ES：Price > Overnight High 定义：BULLISH_BREAKOUT ES：Price < Overnight Low 定义：BEARISH_BREAKDOWN

# 28. Acceptance

第一根突破Bar不能直接确认有效突破。 默认：Acceptance Bars = 1 突破后：至少一个完整5m Bar保持在突破位之外。

# 29. Failed Breakout

如果突破后：价格重新进入Overnight Range 定义：FAILED_BREAKOUT

# 30. RV Expansion

Expansion不能只由价格突破定义。 必须监测：Current RV RV Change RV Percentage Change RV Slope RV Acceleration 核心：Compression
